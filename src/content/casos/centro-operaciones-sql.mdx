## Contexto

Heredé una base de datos cuyas consultas estaban muy desordenadas. Para poder operarla tuve que estudiarlas una por una.

## Problema

Las tareas de la base (abrir un curso, cargar los archivos del día, publicar, cerrar un curso, emitir constancias) dependían de consultas sueltas que había que ejecutar en orden y con los datos correctos.

## Solución

Diseñé un programa de documentación que organiza las consultas por momento de trabajo: empezar el día, abrir un curso o grupo, las tareas de cada día, los dinamizadores, el cierre y la referencia.

Cada tarea es una secuencia de pasos numerados. Un paso indica si modifica datos, trae la consulta lista para copiar con los campos por llenar resaltados, una consulta de comprobación para verificar el resultado y un ejemplo con datos inventados que muestra qué pasa al ejecutarlo.
