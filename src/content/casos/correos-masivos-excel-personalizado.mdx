## Problema

Enviar correos a muchos destinatarios cuando cada uno debe recibir un archivo distinto.

## Solución

Un flujo automatizado recorre la lista de destinatarios, prepara el archivo de Excel que le corresponde a cada uno y envía el correo con ese archivo adjunto.

## El flujo en Power Automate

  <Image

El flujo se inicia manualmente. Obtiene los correos de Outlook y los elementos de una lista de SharePoint, y los recorre uno a uno. En cada vuelta filtra la información y, si se cumple la condición, obtiene el correo correspondiente y crea un elemento nuevo en la lista de SharePoint.
